# Vexor Hub

Repositório oficial do site da **Vexor Hub** — Marketing, Tráfego Pago, Posicionamento e Tecnologia para Negócios Locais.

## 🚀 Como Executar Localmente

1. Para iniciar o servidor local:
   ```bash
   node server.js
   ```
   Acesse: [http://localhost:8888](http://localhost:8888)

2. Para iniciar o túnel público (Cloudflare):
   ```bash
   node start-tunnel.mjs
   ```

## 🔄 Sincronização com o GitHub

Sempre que houver alterações no projeto, o assistente executará automaticamente o commit e push para este repositório (`origin/main`).
